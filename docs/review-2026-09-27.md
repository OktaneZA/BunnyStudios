# Character Studio and production generation review

Reviewed on 27 September 2026. Scope: recent registry, generation contracts, Character Studio, production video API/UI and Studio loading commits (`cc9dada`, `8f13909`, `212d06f`, `239956e`, `2a4fba4`). The working tree was clean before this review. The fixes below are uncommitted.

## Findings fixed

| Finding | Change |
| --- | --- |
| Making a final from a preview could switch off its audio when the request omitted the audio field. | Inherit audio from the recorded preview settings unless explicitly overridden. Added a regression assertion. |
| Model selection could silently substitute a different aspect ratio. | Include the requested aspect ratio in capability filtering and reject unsupported output before spending. Added a regression test. |
| Submission could recalculate a request or price different from the displayed quote. | Production quotes now include a fingerprint of creative and pricing snapshots. The UI sends it on submission; the server rejects a mismatch before reserving funds. The UI refreshes quotes after a conflict. Added a regression test for stale and matching quotes. |
| A final generated on the same endpoint could be described as if it were not a new render. | Mark every regeneration from a preview as a new render; using the same endpoint does not guarantee the same frames. |

The quote fingerprint is optional for existing API callers; this protection is supplied by the production UI. This change does not retrofit the legacy job endpoint.
